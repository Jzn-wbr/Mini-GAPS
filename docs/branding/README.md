# Logo Mini GAPS

Logo retenu : monogramme MG généré par IA avec l’outil intégré de génération
d’images, fichier original `exec-96b922e6-8121-427a-965f-35c8d7bc3318.png`.
`mini-gaps-source.png` conserve le résultat sélectionné sans modification.

Prompt : icône pour une PWA scolaire personnelle, style graphique suisse minimal,
fond clair #f7f8fa, bleu ardoise #3a6282 et bleu nuit #273344. Monogramme MG
entrelacé, géométrie épaisse aux angles arrondis, espace négatif équilibré,
lisible en petit format ; sans livre, calendrier, texte extérieur ou mise en scène.

Les PNG de 32, 180, 192 et 512 px dans `web/assets/` sont des réductions de cette
source, pour le favicon, iOS, le manifeste et les notifications. Aucune dépendance
de traitement d’image n’est ajoutée à l’application. Les icônes du manifeste ont
le rôle `any`, sans déclarer une zone de sécurité `maskable` non vérifiée.
